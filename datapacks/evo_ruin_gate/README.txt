Evo Ruin Gate — datapack
========================

Что делает
----------
Переопределяет loot-таблицу minecraft:chests/ruined_portal и добавляет третий пул:
с шансом ~6% в сундук разрушенного портала попадает компас «Ключ разлома руин»
(имя + lore). Ванильный лут портала не удалён.

Установка
---------
1. Скопируй папку evo_ruin_gate в <мир>/datapacks/
2. /reload (или перезапуск сервера)
3. /datapack enable "file/evo_ruin_gate"

Арена в Незере (medieval.sk)
-----------------------------
ПКМ по обсидиану портала в Оверворлде с ключом-компасом — телепорт в Незер,
арена 100×100 из bedrock + barrier (один раз при первом входе; координаты в
options: ruin_gate_nether_center_x/z, ruin_gate_nether_floor_y).

Выход: /evoruinexit (возврат к месту входа). Админ: /evoruinresetarena —
пересобрать арену при следующем входе.

Важно
------
Новые сундуки порталов получают лут при генерации; уже открытые сундуки не обновятся.
